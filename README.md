# NeoVortex Combo Hub

NeoVortex Combo Hub is a small static site for browsing One Piece-inspired combo routes. It includes searchable combo entries, rarity shortcut filters, a random combo picker, and a focused dialog for viewing and copying full combo sequences.

Public site: https://neovortex-combo.vercel.app

## Project Files

- `index.html` contains the page structure, styling, and browser-side behavior.
- `combos.js` stores the combo data used by the site.
- `assets/` contains the themed images and icons used by the interface.

Because the site is plain HTML, CSS, and JavaScript, it can be opened directly in a browser or deployed as a static site.
